# Vellograph app icon

The app icon is an original folded V: two contrasting forms converge to suggest
comparison and merge. The dark ink-blue tile keeps the mark legible in both
light and dark Dock settings. The source artwork is
[`Artwork/VellographIcon-master.png`](../Artwork/VellographIcon-master.png).
The macOS asset catalog supplies the required 16, 32, 128, 256, and 512 point
sizes at 1x and 2x, with shared raster files where pixel dimensions match.

The 1024-pixel production asset is generated from the source artwork, then
resized for each smaller slot. The built app contains `AppIcon.icns`; its
256-pixel representation was visually inspected and the 16- and 32-pixel
assets remain recognizable.

Generation prompt (built-in image generation tool):

> Original macOS Dock icon for Vellograph, a native diff and merge app. A bold
> abstract V formed by two offset folded sheets converging at a crisp point.
> Deep ink-blue rounded tile, warm off-white left form, blue-green right form,
> restrained dimensional lighting, generous padding, strong 16-pixel
> silhouette. Transparent outside the tile. No text, lens, color wheel,
> rainbow, Apple logo, or borrowed app motif.
